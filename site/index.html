01 / AGENT OS

Agent OS

实现规划、执行、判断、重新规划的目标循环，区分完成、失败、超轮次、预算耗尽和中止五种结果；审批台账记录批准、驳回和过期。

源码：goal-loop.ts · approval-ledger.ts
02 / MEMORY OS

Memory OS

实现事实与假设分类、证据来源引用、冲突关系和确认状态管理；记忆支持争议、替代、过期等状态变更，保留判断依据。

源码：claims/domain/models.py · Core API
03 / PRI × FORGE

人脉与决策综合

决策案件关联业务目标、正反证据和未知事项；推演时检查硬约束、主人否决条件，以及人脉引荐是否获得授权。

源码：decision-case.ts · synthesis.ts
